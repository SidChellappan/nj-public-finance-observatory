The workbook contains `2015 Summary` through `2025 Summary`. If NJ DCA replaces the file at the same URL, do not update the checksum automatically: first compare workbook structure, definitions, target values, formulas, and anomalies, then document the review.

The workbook is opened read-only with cached values (`data_only=True`). Macros are not executed and external links are not refreshed.
