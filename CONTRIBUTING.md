# Contributing corrections

The NJ Public Finance Observatory accepts specific, reproducible corrections to values, missingness, provenance, and explanatory text. Use the [structured data-correction form](https://github.com/SidChellappan/nj-public-finance-observatory/issues/new?template=data-correction.yml) once the repository is publicly authorized.

Please submit one municipality-year-field correction per issue when practical and include:

1. the stable municipality code;
2. the budget year;
3. the field name;
4. the source sheet and cell, or an equally precise public source location;
5. the current Observatory record;
6. the exact proposed correction; and
7. a public source link, precise citation, or public attachment supporting the change.

GitHub issues and attachments are public. Do not submit confidential, private, or personally identifying information. A screenshot can help orient a reviewer, but it should not replace a public link or a citation another person can check.

An accepted correction will preserve the source-reported record, document the review, update the anomaly ledger or extraction rule as appropriate, add a regression test when useful, rebuild every public artifact, and receive a plain-language changelog entry. Opening an issue does not by itself validate or replace a reported value.
